# 🏛️ ЦОН — Халыққа қызмет көрсету орталығы сайты

Қазақстан Республикасының мемлекеттік қызметтер орталығының (ЦОН) лендинг сайты.

## 📁 Файлдар

```
con-site/
├── index.html   # Негізгі HTML беті
├── style.css    # Стильдер
├── app.js       # JavaScript
└── README.md    # Осы файл
```

## ✨ Функциялар

- 🏠 Hero секция — статистика және CTA
- 📋 Танымал қызметтер тізімі (6 карточка)
- 📅 Онлайн кезек алу формасы (модал хабарлама)
- ℹ️ «Біз туралы» бөлімі
- 📞 Байланыс бөлімі
- 📱 Толық адаптивті (мобильді/планшет/desktop)

## 🚀 GitHub Pages арқылы іске қосу

1. GitHub-та жаңа репозиторий ашыңыз
2. Барлық файлдарды жүктеңіз
3. **Settings → Pages → Branch: main → Save**
4. `https://username.github.io/con-site` мекенжайында сайт ашылады

## 🛠️ Технологиялар

- Таза HTML5 / CSS3 / JavaScript (фреймворксіз)
- Google Fonts: Playfair Display + IBM Plex Sans
- CSS Variables, Grid, Flexbox
- IntersectionObserver API (анимациялар)
